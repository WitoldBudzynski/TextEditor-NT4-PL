Privacy Policy

Last updated: September 16, 2026

1. Introduction

This Privacy Policy sets out the rules for data processing in the web application available at https://witoldbudzynski.github.io/TextEditor-NT4-PL/ (hereinafter referred to as the "Application").

2. How the Application Works and Data Processing

The Application is a tool that runs entirely on the client side (in your web browser). We do not operate our own servers and do not collect, store, or analyze your data externally.

3. Access to Google Drive Data

For the Application to work, authorization with a Google account is required. The Application requests access only to the necessary, limited scope (the https://www.googleapis.com/auth/drive.file permission). This means that:

  • The Application can access only the files that you deliberately open with it from the Google Drive menu.
  • The Application reads the contents of the selected file in order to display it in the editor.
  • The Application saves changes to the same file directly on your Google Drive.
  • The Application does not have access to your other files, folders, or Google Drive account settings.

4. Sharing Data with Third Parties

Because the Application does not collect any data, your files and profile information are not shared, sold, or transferred to any third party. All communication takes place directly and securely (via HTTPS) between your browser and Google's API servers.

5. Cookies and Sign-in

The Application does not use its own cookies to track users. Account authorization is handled through standard, secure mechanisms provided by Google (Google Identity Services).

6. Contact

If you have any questions about this Privacy Policy or how the Application works, you can contact its author through the GitHub profile: https://github.com/witoldbudzynski.
